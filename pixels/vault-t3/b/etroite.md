# Colonne étroite

Un paragraphe assez long pour passer à la ligne dans une fenêtre réduite à sa taille minimale, sans jamais faire défiler la page à l horizontale.

| Colonne un | Colonne deux | Colonne trois |
| --- | --- | --- |
| une valeur assez longue | autre valeur | fin |

```js
const uneLigneTresLonguePourVoirLeComportementDuBlocDeCode = 1;
```
