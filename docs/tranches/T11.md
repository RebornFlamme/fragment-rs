## 3. Choix de découpage
1. **La cascade est la pièce dure et indépendante** (`fr-t11-cascade`, tout de suite) : un graphe de jetons
   (valeur ou expression d'`index.css`), résolu à la construction (ADR-005 §2 reste vrai) mais RE-résolu quand on
   surcharge. Contrainte : sans surcharge, `Theme` identique bit à bit à aujourd'hui.
2. **Le thème de coffre attend le coffre et l'apparence** : `fr-t11-themes` dépend de `fr-t2-fs` (événements du
   dossier `.fragment`) et de `fr-t1-reglages` (`cssTheme` dans `appearance.json`).
3. **La scène du thème « Rose »** existe en double dans `pixels/vault-t11/` : `theme.css` pour Fragment, `theme.json`
   pour le candidat, avec les MÊMES jetons (le `theme.css` n'est pas interprété par fragment-rs : non-but).
4. **« Aucun gris neutre »** (theme-plugin test 1) se traduit par un balayage de la capture candidate : aucun pixel
   r = g = b hors des boîtes de texte d'ADR-009 (le TS balaie les styles calculés du DOM, que GPUI n'a pas).
5. **Identité** : l'icône est un ACTIF de la marque, dans le dépôt PRIVÉ (`Fragment/brand/`). ADR-007 règle les
   sources, pas les actifs : publication dans ce dépôt public seulement après accord de l'orchestrateur.
6. Module posé par le socle : `fragment-ui/src/themes`. `fragment-theme` n'est PAS touché par le socle : la cascade
   en possède `lib.rs`.

## 7. Risques
1. **Expressions d'index.css** : un `color-mix` à trois termes, un `calc` mêlant unités, un alias circulaire ; la
   cascade les liste, une valeur non résolue est une erreur de test, pas un repli silencieux.
2. **Bit à bit** : reconstruire `Theme::sombre()` depuis un graphe peut changer un arrondi ; les références pixels
   de T1 le diront (tests de color-mix déjà là).
3. **Actif de marque public** (§3.5) : décision de l'orchestrateur avant `fr-t11-identite`.
4. **Thème clair** : « pas de cadre de focus » et « curseur visible » touchent l'éditeur (T3) et les menus (T1) ;
   une correction dans un module dont la tâche est ouverte = bead bug pour son propriétaire.
5. **visual-diff** : promis par program.md à T11, il dépend en fait de T7 (§1) ; le chef le note au journal.
